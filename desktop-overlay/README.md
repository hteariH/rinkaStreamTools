# Оверлей поверх экрана

Прозрачное окно поверх всех остальных — показывает скримеры на **своём** экране,
пока идёт игра. Browser source в OBS виден только зрителям, поэтому нужен отдельно:
без этого окна стример единственный, кто скример не увидит.

Внутри — та же страница `/screamer`, что и в сцене OBS, только открытая в системном
WebView2. Своего браузера приложение не тащит, поэтому весит около 6 МБ.

## Запуск

Сначала должен работать сам `rinkaStreamTools` (`npm start` в корне проекта) — окно
берёт страницу с него.

```bash
cargo run
```

Адрес по умолчанию — `http://localhost:3777/screamer`. Если сервер на другом порту
или на другой машине в локальной сети:

```powershell
$env:RINKA_HOST='http://192.168.1.50:3777'; cargo run
```

`RINKA_HOST` задаёт и страницу скримеров, и адрес панели в меню трея. Если нужно
подсунуть конкретный адрес страницы (например, с параметрами) — есть `SCREAMER_URL`,
он перебивает `RINKA_HOST`.

## Сборка exe

```bash
cargo build --release
```

Готовый `target/release/rinka-screamer-overlay.exe` самодостаточен — его можно
положить куда угодно и добавить в автозагрузку.

## Управление

Окно невидимо и не ловит мышь, поэтому единственный элемент управления — иконка в
трее:

| Пункт | Что делает |
|---|---|
| Панель управления | открыть `http://localhost:3777/` в браузере по умолчанию |
| Переподключиться | перезагрузить страницу целиком, если сеть отваливалась надолго |
| Выход | закрыть оверлей |

## Что важно знать

- **Игра должна идти в оконном или безрамочном режиме.** Эксклюзивный полноэкранный
  режим перекрывает вообще всё, включая этот оверлей — это ограничение Windows,
  обойти его нельзя.
- Окно не ловит мышь и клавиатуру: клики проходят насквозь в игру.
- Звук идёт со стороны своего компьютера. Если скример должен быть слышен и зрителям,
  добавь в OBS захват звука рабочего стола.
- Скримеры полупрозрачные, чтобы игра просвечивала. Насколько именно — задаётся
  ползунком в панели управления и применяется без перезапуска окна. Можно и адресом:
  `SCREAMER_URL='http://localhost:3777/screamer?opacity=0.6'`.
- Проверить, не запуская стрим — кнопка «Прогнать донат» в панели: скример вылетит и
  в OBS, и в этом окне одновременно.

## Требования к сборочной машине

Rust и MSVC Build Tools с Windows SDK. На машину, где оверлей просто запускается,
ставить ничего не нужно: WebView2 входит в Windows 11, а в Windows 10 обычно приезжает
с обновлениями.
