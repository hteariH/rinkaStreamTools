# Медиа для скримеров

Ассеты Resident Evil здесь не используются намеренно: они принадлежат Capcom, а
игровое аудио вдобавок ловит претензии по контенту на стриме. Всё ниже — материал,
который можно использовать коммерчески без атрибуции.

## Картинки (`img/`)

коммерческое использование без указания авторства. Каждая прогнана через
цветокоррекцию ffmpeg: приглушение цвета до 45%, холодные тени, зерно и виньетка —
именно зерно убирает «стоковость» и приводит кадр к виду хоррор-игры.

## Звуки (`sfx/`)

Freesound, лицензия CC0 1.0 (общественное достояние, атрибуция не требуется),
найдены через API Openverse. Каждый обработан ffmpeg: обрезана тишина в начале,
громкость нормализована до −12 LUFS, в конце фейд — иначе крупный скример звучал
бы тише мелкого, а обрыв давал бы щелчок.

`scream`, `roar`, `roar-low` — крики и рычание для броска.
`stinger`, `swoosh`, `piano-hit` — короткие удары.
`splat`, `growl` — влажный всплеск и рык для крови.
`static` — помехи радио. `drone` — низкий гул для нагнетания.

## Замена

Файлы можно менять на свои, не трогая код: имена перечислены в `IMAGES` и `SOUNDS`
в начале [screamer.js](../js/screamer.js). Если добавляешь новые — пропиши их там
и укажи в наборе нужной вариации.
