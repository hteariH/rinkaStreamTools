# rinkaStreamTools

Набор оверлеев для стрима, который живёт целиком на твоём компьютере: розыгрыш по
команде в чате, общая цель сбора из нескольких донат-площадок, алерты донатов и
скримеры. Всё поднимается на одном локальном порту — в OBS добавляются обычные
**Browser Source** с адресами `http://localhost:3777/…`, наружу ничего не торчит.

Проект объединяет два прежних: [rinkaRaffle](https://github.com/hteariH/rinkaRaffle)
(розыгрыш) и rinaDonatesAggragator (сбор донатов). Java-часть второго переписана на
Node, поэтому теперь это одна программа с одним запуском и общей панелью управления.

## Что внутри

| Оверлей | Адрес | Что показывает |
|---|---|---|
| Розыгрыш | `/raffle` | счётчик участников, последнего вошедшего, победителя, обратный отсчёт |
| Цель сбора | `/goal` | прогресс-бар с суммой всех площадок сразу |
| Алерты донатов | `/alerts` | «Имя — сумма» и текст сообщения |
| Скримеры | `/screamer` | случайный скример на донат выше порога |

Управление — веб-панель на `http://localhost:3777/`: там же настройки, тестовый
донат и лог. Терминал не нужен.

## Как запустить

**1. Скрипт-запускалка (нужен Node.js LTS)**
- Windows — двойной клик по `start.bat`
- macOS/Linux — `./start.sh`

Скрипт сам поставит зависимости при первом запуске.

**2. Вручную (для разработки)**
```bash
npm install
npm start
```

**3. Standalone-сборка без Node**
```bash
npm ci
npm run build:exe   # → dist/rinkaStreamTools(.exe) для текущей ОС (Node 20+)
```
Рядом с исполняемым файлом должны лежать `config.json` и папка `public/`.

## Настройка

Всё правится в панели и сохраняется в `config.json` рядом с программой. Файл
создаётся сам при первом запуске; образец — `config.example.json`.

### Розыгрыш

Сообщения берутся из **[AxelChat](https://3dproger.github.io/AxelChat/)** по его
локальному WebSocket API — отдельно к YouTube / Kick / prime.gs подключаться не нужно.

1. Открой AxelChat → **Settings → Developers**.
2. Убедись, что **State: Ok**, порт `8356` (URL `ws://127.0.0.1:8356`).

Один зритель = одна запись (уникальность по площадке и имени). Команда матчится по
первому слову сообщения без учёта регистра, поэтому `!хил плиз` тоже засчитывается.
Уже выпавшие победители в следующих розыгрышах не участвуют, пока не нажат «Сбросить».

Тем у оверлея розыгрыша пять: `default`, `grimoire`, `rune`, `blood`, `glitch` —
переключаются в панели на лету, перезагружать источник в OBS не нужно.

### Донат-площадки

И DonationAlerts, и Donatello читаются через **страницу виджета** — ту самую ссылку,
которую ты вставляешь в OBS. Логин и пароль не нужны и нигде не хранятся.

- **DonationAlerts** — ссылка на виджет цели вида
  `https://www.donationalerts.com/widget/goal/<id>?token=<token>`
- **Donatello** — ссылка на виджет вида
  `https://donatello.to/widget/<widgetId>/token/<token>`

Каждая площадка ведёт свой счётчик в своей валюте. Чтобы сложить их в одну цель, у
источника есть **множитель** — на него умножается сумма перед сложением. Курсы
намеренно не тянутся из сети: они меняются, а цифра на экране во время эфира прыгать
не должна. Если обе площадки в одной валюте — оставь `1`.

Плюс есть **добавка вручную** — наличные, крипта и всё, что прошло мимо площадок.

Суммы опрашиваются раз в минуту и внеочередно через пару секунд после каждого доната.

### Алерты

Показываются по одному, очередью. Можно задать длительность и минимальную сумму.

**Звук:** положи файл `public/alert.mp3` — он заиграет вместе с алертом. Файла нет —
алерт просто молчит.

### Скримеры

На донат выше порога оверлей проигрывает случайный эффект из семи вариаций
(бросок на камеру, подсечка, строб, фонарь, кровь на объективе, VHS-помехи,
медленное проявление) со случайной картинкой и звуком из своего набора.

Пороги задаются **прямо в валютах**, курсы не применяются: донат сравнивается с
порогом той же валюты, в которой пришёл. `default` — для валют, которых нет в списке.
Если для валюты донатера порога нет, но DonationAlerts пересчитал сумму сам
(`amount_in_user_currency`), сверка идёт с пересчитанной суммой в базовой валюте.

Ползунок «перекрытие игры» задаёт прозрачность — скример не закрывает картинку
полностью. Значение можно подобрать и прямо в адресе: `/screamer?opacity=0.6`.

Медиа лежит в `public/screamers`: фотографии с Pexels (лицензия разрешает
коммерческое использование без атрибуции), прогнанные через цветокоррекцию, и звуки
CC0 с Freesound. Ассеты Resident Evil не используются намеренно — они принадлежат
Capcom и ловят претензии по контенту на стриме.

## Отладочные адреса

| Адрес | Что делает |
|---|---|
| `/goal?theme=neon` | перебить тему оверлея цели, не трогая настройки |
| `/alerts?demo` | показать пример алерта, ничего не ожидая от сервера |
| `/screamer?demo` | прогнать все вариации скримера подряд |
| `/screamer?variant=lunge` | всегда показывать одну конкретную вариацию |
| `/screamer?ping` | мигнуть меткой при подключении — проверить, что оверлей жив |
| `/screamer?opacity=0.6` | подобрать перекрытие вживую |

Кнопка «Прогнать донат» в панели гоняет тестовый донат по всей цепочке: алерт и
скример увидишь так же, как на эфире. Общая сумма от теста не растёт.
