# rinkaStreamTools

[![Проверки](https://github.com/hteariH/rinkaStreamTools/actions/workflows/ci.yml/badge.svg)](https://github.com/hteariH/rinkaStreamTools/actions/workflows/ci.yml)
[![Релиз](https://img.shields.io/github/v/release/hteariH/rinkaStreamTools)](https://github.com/hteariH/rinkaStreamTools/releases/latest)

### [Скачать для Windows — rinkaStreamTools-win-x64.zip](https://github.com/hteariH/rinkaStreamTools/releases/latest/download/rinkaStreamTools-win-x64.zip)

Распаковать и запустить `rinkaStreamTools.exe`. Ставить ничего не нужно.

Набор оверлеев для стрима, который живёт целиком на твоём компьютере: розыгрыш по
команде в чате, общая цель сбора из нескольких донат-площадок, топ донатеров, лента
последних донатов, что сейчас играет, алерты донатов и скримеры. Всё поднимается на одном локальном порту — в OBS добавляются обычные
**Browser Source** с адресами `http://localhost:3777/…`, наружу ничего не торчит.

Проект объединяет два прежних: [rinkaRaffle](https://github.com/hteariH/rinkaRaffle)
(розыгрыш) и rinaDonatesAggragator (сбор донатов). Java-часть второго переписана на
Node, поэтому теперь это одна программа с одним запуском и общей панелью управления.

## Что внутри

| Оверлей | Адрес | Что показывает |
|---|---|---|
| Розыгрыш | `/raffle` | счётчик участников, последнего вошедшего, победителя, обратный отсчёт |
| Цель сбора | `/goal` | прогресс-бар с суммой всех площадок сразу |
| Топ донатеров | `/top` | кто сколько занёс, одним списком по обеим площадкам |
| Последние донаты | `/recent` | бегущая строка «имя — сумма» по последним донатам |
| Сейчас играет | `/track` | название и исполнитель текущего трека, с обложкой |
| Опрос в чате | `/poll` | вопрос, варианты и полосы голосов |
| Алерты донатов | `/alerts` | «Имя — сумма» и текст сообщения |
| Скримеры | `/screamer` | случайный скример на донат выше порога |

Управление — панель: настройки, список участников, тестовый донат и лог. Она
открывается в окне приложения, поэтому терминал стримеру не нужен вовсе. В том же
приложении живёт прозрачный оверлей поверх игры со скримерами: Browser Source в OBS
видят только зрители, и без него стример остаётся единственным, кто скример не увидит.

## Как запустить

**Готовая папка — то, что отдаётся стримеру.**
[Скачай архив](https://github.com/hteariH/rinkaStreamTools/releases/latest/download/rinkaStreamTools-win-x64.zip)
(ссылка всегда ведёт на последний релиз; все версии —
[на странице релизов](https://github.com/hteariH/rinkaStreamTools/releases)) и распакуй.
Внутри один файл для запуска:

```
rinkaStreamTools.exe     <- по нему щёлкать
server/                  <- сервер и медиа, трогать не надо
```

Двойной клик — открывается окно панели, оверлеи в OBS начинают работать. Крестик
прячет окно в трей и ничего не роняет; закрыть совсем — из трея «Выход». Ставить
Node или Rust на эту машину не нужно.

Собрать самому (Node 20+ и Rust на сборочной машине):

```bash
npm ci
cd desktop && cargo build --release && cd ..
npm run build:exe
```

`cargo build` собирает окно, `build:exe` — сервер, и он же складывает всё в `dist/`.
Весит около 107 МБ: внутрь зашит Node. Отдавать папку целиком — приложение без
подпапки `server` не работает и скажет об этом.

**Для разработки** сервер и окно запускаются раздельно:

```bash
npm install
npm start
```
Панель тогда открывается в браузере на `http://localhost:3777/`. Окно приложения,
если нужно, — `cd desktop && cargo run`: сервера рядом с собой оно не найдёт и
подключится к уже запущенному.

Для запуска без сборки Rust остались `start.bat` (Windows) и `./start.sh` — они
поднимают только сервер и сами ставят зависимости при первом запуске.

Подробности про окно и трей — в [desktop/README.md](desktop/README.md).

## Где лежат данные и как обновляться

Настройки, таблица донатеров, лента последних донатов и гифки со звуками алертов
лежат **не в папке программы**, а в профиле пользователя:

```
%APPDATA%
inkaStreamTools  config.json      <- настройки из панели
  donors.json      <- таблица донатеров
  recent.json      <- лента последних донатов
  media/           <- гифки и звуки алертов
```

Поэтому **обновление ничего не теряет**: скачал новый архив, распаковал куда угодно,
запустил — настройки и донаты на месте. Раньше данные лежали рядом с exe, и это
ломалось об обычную привычку: браузер распаковывает архив в соседнюю папку «имя (1)»,
человек запускает оттуда и оказывается с чистыми настройками, а прошлые донаты остаются
в старой папке. При первом запуске новой версии данные, лежащие рядом с exe, переезжают
в профиль сами — копированием, так что откат на старую версию ничего не ломает.

Путь видно в панели, на вкладке «Источники для OBS», там же кнопка «Открыть папку».

**Портативный режим.** Если программу носят с собой (флешка, второй компьютер), положи
рядом с `rinkaStreamTools.exe` пустую папку `data` — всё будет храниться в ней, а профиль
не тронется.

## Настройка

Всё правится в панели и сохраняется в `config.json` в папке данных. Файл создаётся сам
при первом запуске; образец — `config.example.json` рядом с сервером.

### Розыгрыш

Сообщения берутся из **[AxelChat](https://3dproger.github.io/AxelChat/)** по его
локальному WebSocket API — отдельно к YouTube / Kick / prime.gs подключаться не нужно.

1. Открой AxelChat → **Settings → Developers**.
2. Убедись, что **State: Ok**, порт `8356` (URL `ws://127.0.0.1:8356`).

Один зритель = одна запись (уникальность по площадке и имени). Команда матчится по
первому слову сообщения без учёта регистра, поэтому `!хил плиз` тоже засчитывается.
Уже выпавшие победители в следующих розыгрышах не участвуют, пока не нажат «Сбросить».

Обратный отсчёт до конца розыгрыша ставится из панели (`90`, `5m`, `2m30s`, `1:30`), его
можно поставить на паузу и снять. Галочка **«Сразу опубликовать победителя»** разыграет
победителя сама, как только отсчёт дойдёт до нуля, — не надо ловить момент и жать
«Разыграть» в прямом эфире. На паузе отсчёт не срабатывает.

Тем у оверлея розыгрыша пять: `default`, `grimoire`, `rune`, `blood`, `glitch` —
переключаются в панели на лету, перезагружать источник в OBS не нужно.

### Опрос в чате

Зрители голосуют **номером варианта** в том же чате, который уже читается ради
розыгрыша: отдельного подключения опросу не нужно. Написал `2` — голос за второй
вариант. Если в чате и без опроса летают числа, можно задать команду, и тогда голосом
считается только `!голос 2`.

Один зритель — один голос. Ключ тот же, что у розыгрыша: площадка плюс имя, потому что
идентификатор автора у AxelChat для части площадок меняется от сообщения к сообщению.
Пока голосование открыто, можно передумать — промахнулся мимо цифры, исправился; это
выключается настройкой.

Голосом считается **сообщение из одной цифры и ничего больше**: «2» — голос, «2 балла из
10» — обычная реплика. Иначе в подсчёт попадали бы чужие разговоры.

Вариантов до девяти: голосуют одним символом, а двузначные номера в чате уже не набрать
без ошибок.

«Закрыть» останавливает приём голосов, но итоги остаются на оверлее — их обычно обсуждают
уже после отсчёта; «Убрать с экрана» прячет опрос совсем. Отсчёт можно не ставить вовсе
(0 секунд) и закрыть руками.

Ведущий вариант подсвечивается **только после закрытия и только если он один**: на живом
голосовании подсветка прыгала бы туда-сюда, а при равенстве объявлять победителем того,
кто выше в списке, было бы враньём.

### Донат-площадки

И DonationAlerts, и Donatello читаются через **страницу виджета** — ту самую ссылку,
которую ты вставляешь в OBS. Логин и пароль не нужны и нигде не хранятся.

- **DonationAlerts** — ссылка на виджет цели вида
  `https://www.donationalerts.com/widget/goal/<id>?token=<token>`
- **Donatello** — ссылка на виджет вида
  `https://donatello.to/widget/<widgetId>/token/<token>`

Каждая площадка ведёт свой счётчик в своей валюте. Чтобы сложить их в одну цель, у
источника есть **множитель** — на него умножается сумма перед сложением. Курсы
намеренно не тянутся из сети: они меняются, а цифра на экране во время эфира прыгать
не должна. Если обе площадки в одной валюте — оставь `1`.

Плюс есть **добавка вручную** — наличные, крипта и всё, что прошло мимо площадок.

Тем четыре, и **у цели, топа, ленты и трека своя**: в одной сцене их обычно ставят в
одной теме, но не всегда — тонкая полоса `slim` под игрой и панель топа в углу уживаются
лучше, чем две одинаковые панели.

| Тема | Стиль |
|---|---|
| `default` | тёмная панель, золото |
| `slim` | только текст, без панели |
| `neon` | циан по обсидиану, рамка и скан-линии |
| `hud` | циановая капсула |

У цели `hud` кладёт подпись на место процента, поэтому если подписи нет — там
показывается процент, и полоса не остаётся пустой.

Тему можно перебить прямо в адресе источника, не трогая настройки: `/goal?theme=neon`,
`/top?theme=neon`, `/recent?theme=neon`, `/track?theme=neon`.

**Цвет ника и суммы** задаётся отдельно, карточкой «Цвета» в панели, и действует сразу на
три оверлея — алерты, топ и ленту: это одни и те же две роли, и разъезжаться по оверлеям
им незачем. Пока цвет не задан, его выбирает тема; кнопка «как в теме» возвращает всё
обратно. Свечение и рамки остаются от темы — меняется только цвет самого текста.

Если тема цели была настроена до того, как темы разъехались, при первом запуске новой
версии она переносится на топ и на ленту: обновление программы не должно молча вернуть
два оверлея к `default` и разъехать собранную сцену.

Суммы опрашиваются раз в минуту и внеочередно через пару секунд после каждого доната.

### Топ донатеров

Кто сколько занёс за всё время — одним списком по обеим площадкам.

Донаты **объединяются по имени**: один и тот же ник на DonationAlerts и на Donatello
считается одним человеком. Общего id у зрителя между площадками нет, и ник —
единственное, за что можно зацепиться; обратная сторона в том, что два разных человека
с одинаковым ником сложатся в одного. Регистр и краевые пробелы не в счёт, так что
`MaxPower` и `maxpower` — один и тот же зритель.

Суммы приводятся к валюте цели теми же множителями площадок, что и сама цель, — иначе
гривны с одной и доллары с другой сложились бы в бессмыслицу.

Анонимные донаты в список не идут: приписать их некому, а сваливать всех в одного
«Анонима» значит выдумать донатера, которого нет. Сколько их было и на какую сумму,
видно в панели отдельной строкой.

Таблица лежит в `donors.json` в папке данных и переживает перезапуск: эфир идёт часами,
и ронять её на ребуте сервера нельзя. Копится она из живых событий сокета, поэтому донаты
**до** первого запуска в неё не попадут. Кнопка «Очистить таблицу» в панели обнуляет всё;
тестовый донат из панели в таблицу не идёт, чтобы не портить её в эфире.

**Правится руками.** В панели видно таблицу целиком, а не только те места, что уходят на
оверлей. Крестик убирает донатера — например с ником, которому не место в кадре, — а
форма рядом добавляет донат мимо площадок. Ручная сумма считается сразу в валюте цели:
множители площадок к ней не применяются, площадки в этом донате не участвовали. Саму цель
это не двигает — для неё есть «добавка вручную».

Формат — в образце `donors.example.json` рядом с сервером. Если надо занести донаты,
прошедшие мимо программы (наличные, старый сбор, эфир до первого запуска), переименуй
образец в `donors.json` и правь руками, пока сервер выключен: он читает файл на старте
и с этого места продолжает. Суммы в файле уже приведены к валюте цели — множители к
ним второй раз не применяются.

### Последние донаты

Донаты по обеим площадкам сразу, по одному, свежие первыми. Топ отвечает на вопрос «кто
занёс больше всех за всё время», лента — «что было только что».

Показывается она в двух видах, и это не одно и то же:

- **На оверлее — бегущая строка**: только «имя — сумма», по кругу, во всю ширину
  источника. Полоса едет, и прочитать на ходу успевают ровно это. Сколько последних
  донатов в круге и с какой скоростью он едет (пикселей в секунду) — задаётся в панели;
  скорость можно подобрать и вживую, адресом `/recent?speed=120`.
- **В панели — полный список с сообщениями**: кто, сколько, во сколько и что написал.
  Она открыта на втором мониторе, там это и надо видеть.

Сообщения зрителей **на оверлей не уходят вовсе** — не «спрятаны настройкой», а не
отправляются: чего нет в кадре, то не попадёт на стрим по недосмотру. В панели они
обрезаны до 140 символов.

Суммы показываются **в той валюте, в которой пришли**, и множители площадок к ним не
применяются: множители нужны, чтобы складывать, а в ленте складывать нечего — каждая
строка это один донат.

Анонимные донаты здесь **есть**, в отличие от топа: приписать донат некому, но событие
было, и в ленте ему место — показывается «Аноним».

Лента лежит в `recent.json` в папке данных
и переживает перезапуск. Хранится полсотни последних: в панели видно их все, в бегущей
строке — сколько задано, и после «покажи не 3, а 10» лента не начинает копиться заново.
Кнопка «Очистить ленту» обнуляет её, не трогая топ; тестовый донат из панели в ленту не
идёт.

**Правится руками.** Крестик у строки убирает донат из ленты — ник или сообщение бывают
такими, что в кадре им не место. Рядом форма, чтобы добавить донат мимо площадок:
наличные, перевод на карту, донат из чужой программы. Лента и топ — разные списки, и
добавленное в одно не попадает в другое.

Формат — в образце `recent.example.json`; он показывает тот же эфир, что и
`donors.example.json`, только донатами по одному, а не суммами. Свежий донат — первый в
списке; суммы тут в валюте доната, не приведённые. Заполнять руками так же: переименовать
образец и править при выключенном сервере.

### Сейчас играет

Название и исполнитель текущего трека — карточкой в углу сцены, с обложкой и полосками
эквалайзера. Музыки нет — карточки нет: пустое «ничего не играет» полстрима висеть не
должно.

Откуда берётся трек — на выбор, в панели:

- **Медиасессия Windows** (по умолчанию). Это тот же источник, из которого всплывашка
  громкости знает, что у тебя играет: Spotify, ролик во вкладке браузера, AIMP,
  foobar2000. Плеер уже рассказал системе название — настраивать в нём **ничего не надо**.
- **Текстовый файл**, который пишет сам плеер, — если в медиасессию он не отдаётся.
  foobar2000, AIMP и Snip так умеют. Формат: одна строка «Исполнитель — Название» или
  две, где первая название, а вторая исполнитель. Пустой файл значит тишину.

**Фильтр приложения** нужен, когда играет не только плеер. У стримера в браузере может
идти ролик или своя же трансляция — медиасессия честно покажет её название. Впиши в
фильтр кусок имени приложения (`Spotify`), и остальное перестанет попадать в кадр; какие
приложения система видит прямо сейчас, панель показывает под полем.

**Обложка.** Свою обложку Spotify наружу не отдаёт: в медиасессии она лежит потоком,
который не прочитать, а Web API требует авторизации. Поэтому картинка ищется по
исполнителю, названию и альбому в открытых каталогах — сначала iTunes, потом Deezer, без
ключей и регистрации. Альбом Spotify называет точно, и по нему из выдачи выбирается
нужное издание, а не первый попавшийся сборник. Обычно это ровно та же картинка, что в
плеере; у концертников и ремиксов каталог иногда отдаёт другое издание. Не нашлось —
оверлей покажет трек без картинки. Наружу при этом уходит **только название трека**: ни
донатов, ни зрителей, ни ников в этих запросах нет, и галочка «Показывать обложку»
выключает их совсем.

Длинное название не обрезается, а едет строкой — скорость задаётся в панели, подобрать
можно вживую адресом `/track?speed=80`. На паузе оверлей по умолчанию прячется; если
показывать — полоски эквалайзера замирают, и это видно с одного взгляда.

Кнопка «Показать демо-трек» нужна, чтобы поставить источник на место в OBS, не дожидаясь
смены песни: демо висит, пока не сменится настоящий трек.

Опрос медиасессии делает маленький скрипт на PowerShell (`src/nowplaying/session.ps1`) —
из Node в WinRT иначе не дотянуться. Он живёт одним процессом рядом с сервером и уходит
следом за ним. На не-Windows медиасессии нет вовсе: там остаётся файловый источник.

### Алерты донатов по тирам

Донат попадает в **тир** — по сумме. Тиров по умолчанию три: мелкий, средний и крупный.
Тир задаёт, как долго висит алерт, насколько он заметный на экране и вылетает ли на него
скример.

| Тир | Порог, USD | Скример |
|---|---|---|
| Мелкий | от 1 | нет |
| Средний | от 5 | да |
| Крупный | от 20 | да |

Пороги задаются **прямо в валютах**, курсы не применяются: донат сравнивается с порогом
той же валюты, в которой пришёл. `default` — для валют, которых в списке нет. Если для
валюты донатера порога нет, но DonationAlerts пересчитал сумму сам
(`amount_in_user_currency`), сверка идёт с пересчитанной суммой в базовой валюте.

**Каждый тир включается отдельно для каждой площадки.** Например, если на DonationAlerts
уже настроены свои алерты, а дублировать их не хочется — выключаешь там нужные тиры, и
показываться будут только донаты с Donatello.

Тир, выключенный для площадки, в расчёт не идёт вовсе: донат с неё уходит в тир пониже,
который для этой площадки включён, а не пропадает молча. Донат в 75 USD с Donatello при
выключенном для неё крупном тире покажется как средний.

Тиры, пороги, названия и длительности правятся в панели; тир можно оставить без единой
включённой площадки — тогда он просто не сработает.

#### Гифки, звуки и тема у тира

У каждого тира свой вид: **тема** карточки (те же четыре, что у остальных оверлеев),
**гифки** и **звуки**. Гифок и звуков можно выбрать сколько угодно — на каждый донат
берётся случайная пара, и две одинаковых подряд не выпадают: за эфир один и тот же
котик приедается.

Файлы добавляются в панели («Файлы для алертов» → «Добавить гифку» / «Добавить звук») и
лежат в папке `media` рядом с конфигом — то есть рядом с exe, а не внутри `public/`. Так
их видно из проводника, и обновление программы их не затирает. Гифкой может быть любая
картинка, которую понимает браузер (`gif`, `png`, `jpg`, `webp`, `avif`), звуком — `mp3`,
`ogg`, `wav`, `m4a`, `opus`, `flac`. Потолок на файл — 25 МБ.

Файл, выбранный у тира и потом убранный из папки, просто перестаёт выпадать: битой
картинки в кадре не будет. Убрать файл насовсем — крестик в списке; из тиров он при этом
пропадёт сам.

**Громкость** звуков — общая, ползунком в панели.

**Общий звук на все алерты** остался: файл `public/alert.mp3` играет на тирах, у которых
своих звуков не выбрано. Нет и его — алерт молчит.

#### Озвучка сообщений

Сообщение донатера можно читать вслух. Устроено как у DonationAlerts: синтезирует не
браузер, а сервер, оверлею приезжает ссылка на готовый звук. Движка два, переключаются в
панели:

| Движок | Чем хорош | Чем плох |
|---|---|---|
| **Голос Windows** | бесплатно, офлайн, ничего не настраивать | звучит роботом; нужен голос нужного языка |
| **ElevenLabs** | живой голос | по ключу и лимитам, бесплатный план некоммерческий |

Читаются **только те тиры, где отмечено «Читать сообщение»**. Ссылки из сообщения
выкидываются, а длина режется (по умолчанию 200 символов): у облака это прямые деньги,
у офлайнового голоса — минута чтения вслух. Перед сообщением читается имя донатера, если
это включено.

Алерт не зависит от озвучки: не синтезировалось — донат всё равно покажется, молча, а
причина уйдёт в лог. Если сообщение длиннее, чем висит карточка, карточка дожидается
конца чтения: убирать её из-под голоса нельзя, зритель дослушивает то, чего уже не видно.

**Голос Windows.** Ставится галочка, жмётся «Обновить голоса» — и в списке появляется то,
что есть в системе. Тут есть ловушка, из-за которой стоит посмотреть на список до эфира:
**голос читает только свой язык**. Английский голос на русском сообщении не ругается, а
молча выдаёт тишину — панель поэтому предупреждает, если русского голоса в списке нет, а
сервер в таком случае пишет в лог «голос не прочитал текст», а не делает вид, что всё
хорошо. Русский голос ставится в Windows: Параметры → Время и язык → Речь → Добавить
голоса → Русский. Важно: в списке видно голоса SAPI5, и если система поставит только
новый вариант (OneCore), голос появится у Экранного диктора, но не здесь — тогда помогает
установка русского языка целиком, с речевыми компонентами.

Скорость речи — ползунком, от -10 до 10.

**ElevenLabs.** Нужен ключ из личного кабинета и голос. У ключа должны быть права на
голоса, синтез и профиль: иначе придёт отказ, и это **не то же самое**, что неверный
ключ — панель показывает ответ ElevenLabs как есть, по нему видно, какого права не
хватает. Голос выбирается из списка аккаунта, id можно и вписать руками. Там же виден
остаток лимита: сколько символов потрачено и на сколько примерно сообщений хватит.

Про их тарифы: бесплатный план даёт 10 000 кредитов в месяц, модель `eleven_flash_v2_5`
стоит 0.5 кредита за символ (примерно 200 сообщений по 100 символов),
`eleven_multilingual_v2` — 1 кредит. Русский поддерживают обе. Но бесплатный план
**некоммерческий**, требует упоминания `elevenlabs.io` в заголовке опубликованного и не
даёт брать голоса из библиотеки через API — для стрима с донатами нужен платный, от $6 в
месяц. Решает это владелец ключа.

Ключ лежит в `config.json` открытым текстом — как и ссылки на виджеты донат-площадок.
В панель он обратно не отдаётся: поле после перезагрузки пустое, а рядом написано, что
ключ на сервере есть.

### Скримеры

**По умолчанию выключены** — включаются галочкой в панели: такое включают осознанно, а
не обнаруживают в прямом эфире. У тех, кто их уже включил, настройка своя и остаётся.

На тир с включённым скримером оверлей проигрывает случайный эффект из семи вариаций
(бросок на камеру, подсечка, строб, фонарь, кровь на объективе, VHS-помехи, медленное
проявление) со случайной картинкой и звуком из своего набора.

Вариации разной силы, и подбираются они под тир: подсечка и VHS-помехи достаются мелким
и средним донатам, бросок на камеру, строб и кровь — только крупным. Две одинаковых
подряд не выпадают.

**Проверка, которая не пугает.** В списке вариаций есть `heart` — большое сердечко вместо
лица, с мягким сигналом вместо крика. По нему видно, что оверлей жив, стоит где надо и с
нужной прозрачностью, а проверять связку перед эфиром, вздрагивая каждый раз, невозможно.
Выбирается в панели («сердечко — проверка, которая не пугает») или адресом
`/screamer?variant=heart`. На настоящий донат сердечко не выпадет никогда: оно выведено
из случайного подбора.

Выбранная вручную вариация показывается сама по себе, мимо тиров и порогов, — иначе
сердечко с суммой в один доллар не показало бы ничего, потому что мелкий тир скример не
вызывает.

Ползунок «перекрытие игры» задаёт прозрачность — скример не закрывает картинку
полностью. Значение можно подобрать и прямо в адресе: `/screamer?opacity=0.6`.

Медиа лежит в `public/screamers`: фотографии с Pexels (лицензия разрешает
коммерческое использование без атрибуции), прогнанные через цветокоррекцию, и звуки
CC0 с Freesound. Ассеты Resident Evil не используются намеренно — они принадлежат
Capcom и ловят претензии по контенту на стриме.

Скримеры на **своём** экране, а не только у зрителей — второе окно приложения, см.
[desktop/README.md](desktop/README.md).

## Отладочные адреса

| Адрес | Что делает |
|---|---|
| `/goal?theme=neon` | перебить тему оверлея цели, не трогая настройки |
| `/top?theme=neon` | то же для топа донатеров |
| `/top?demo` | показать пример топа, ничего не ожидая от сервера |
| `/recent?theme=neon` | то же для ленты последних донатов |
| `/recent?demo` | показать пример строки, ничего не ожидая от сервера |
| `/recent?speed=120` | подобрать скорость бегущей строки вживую |
| `/poll?demo` | показать пример опроса, ничего не ожидая от сервера |
| `/poll?theme=neon` | перебить тему опроса, не трогая настройки |
| `/track?demo` | показать пример карточки трека, ничего не ожидая от сервера |
| `/track?theme=neon` | то же для оверлея «сейчас играет» |
| `/track?speed=80` | подобрать скорость бегущего названия вживую |
| `/alerts?demo` | показать пример алерта, ничего не ожидая от сервера |
| `/alerts?theme=neon` | перебить тему алертов, не трогая настройки тиров |
| `/screamer?variant=heart` | сердечко: проверка, которая не пугает |
| `/screamer?demo` | прогнать все вариации скримера подряд |
| `/screamer?variant=lunge` | всегда показывать одну конкретную вариацию |
| `/screamer?ping` | мигнуть меткой при подключении — проверить, что оверлей жив |
| `/screamer?opacity=0.6` | подобрать перекрытие вживую |

Кнопка «Прогнать донат» в панели гоняет тестовый донат по всей цепочке: алерт и
скример увидишь так же, как на эфире. Общая сумма от теста не растёт.

## Разработка

Тесты — на логику тиров и на целость набора скримеров: что каждая вариация находит свои
картинки и звуки и что на каждый тир со скримером есть чем ответить. Пустой экран вместо
скримера посреди эфира иначе ничем не ловится.

```bash
npm test
```

Розыгрыш можно погонять без запущенного AxelChat:

```bash
npm run mock
```
Эмулятор шлёт тестовые сообщения на тот же порт, что и настоящий.

## Сборка и релиз

Тесты и сборка окна гоняются на каждый push — [.github/workflows/ci.yml](.github/workflows/ci.yml).

Релиз собирается по тегу: прогоняются тесты, собирается окно, собирается сервер,
проверяется раскладка папки, и архив вешается на релиз —
[.github/workflows/release.yml](.github/workflows/release.yml).

```bash
git tag v1.0.0
git push origin v1.0.0
```

Готовый `rinkaStreamTools-win-x64.zip` появится на странице релизов. Прогнать сборку без
тега можно вручную через workflow_dispatch.
